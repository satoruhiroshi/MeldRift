# MeldRift

MeldRift is a high-performance, real-time data processing framework for scalable server-client architectures.

MeldRift is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MeldRift.git`
2. `cd MeldRift`
3. Install in editable mode: `pip install -e .`

## Configuration

MeldRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
